# ⚡ Quick Start - 5 Minutes

Deploy English Booster to Vercel in 5 minutes!

## 🚀 Steps

### 1. GitHub (2 minutes)
```
1. Go to: github.com
2. Sign up (or login)
3. New repository → "english-booster" → Public → Create
4. Upload files: index.html, app.js, styles.css, manifest.json, vercel.json
5. Commit changes
```

### 2. Vercel (2 minutes)
```
1. Go to: vercel.com
2. Sign up with GitHub
3. New Project → Import "english-booster"
4. Deploy (leave all settings default)
5. Wait 60 seconds
```

### 3. Done! (1 minute)
```
1. Click your new URL: https://english-booster-xxxxx.vercel.app
2. Open Settings ⚙️
3. Add your Supabase credentials
4. Save
```

## ✅ That's it!

Your app is live and accessible worldwide!

### 📱 Install as Mobile App

**iPhone:** Safari → Share → Add to Home Screen  
**Android:** Chrome → Menu → Add to Home screen  
**Desktop:** Chrome → Install icon in address bar
